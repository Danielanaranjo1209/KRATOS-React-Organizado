# KRATOS React

Proyecto académico ficticio para actividades físicas y planificación semanal.

## Estructura
- `src/components`: componentes reutilizables.
- `src/pages`: páginas separadas.
- `src/data.js`: datos de las actividades.
- `src/App.jsx`: rutas de React Router.

## Vistas
- Inicio: `/`
- Actividades: `/actividades`
- Detalle dinámico: `/actividades/fuerza` (también `cardio`, `yoga`, `hiit`, `caminata` o `core`)
- Planificación: `/planificacion`
- Contacto: `/contacto`
- Página 404: cualquier ruta inexistente

## Ejecutar
```bash
npm install
npm run dev
```
